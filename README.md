# PDF-to-Markdown

Convert PDF documents into cleaner, AI-friendly Markdown with Elegxo AI.

## Basic PDF-to-Markdown

The Basic PDF to Markdown converter processes the PDF locally in your browser without table extraction. It is intended for standard PDF content such as text, headings, paragraphs, and lists.

## Advanced PDF-to-Markdown

The Advanced version uses the Elegxo AI cloud function with open-source tools for server-side conversion. It provides more advanced PDF processing, including table extraction and conversion into Markdown tables, along with richer document structure.

## Basic vs Advanced

| Feature | Basic | Advanced |
|---|---|---|
| Processing | Local browser | Elegxo AI cloud function |
| PDF to Markdown | ✓ | ✓ |
| Text conversion | ✓ | ✓ |
| Headings and lists | ✓ | ✓ |
| Table extraction | — | ✓ |
| Markdown tables | — | ✓ |
| Richer document structure | Basic | Advanced |
| Server-side processing | — | ✓ |
| Open-source processing tools | — | ✓ |
